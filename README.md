# FIAP-SPRINT-2

Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de apresentar nossa solução para o problema proposto pela Jovi. A proposta foi transformada em uma aplicação web moderna e interativa, focada em proporcionar uma experiência intuitiva e eficiente para o usuário.

O site foi desenvolvido utilizando tecnologias de front-end como:

HTML
CSS
JavaScript

Além disso, o projeto também conta com um arquivo em Python, criado para simular a experiência ideal que desenvolvemos para a interface. Essa simulação ajuda a demonstrar de forma prática o funcionamento da solução proposta e a visão da experiência do usuário que imaginamos para o projeto.

O JavaScript foi utilizado para adicionar interatividade ao site, incluindo o desenvolvimento de um sistema de login com validação dos campos, garantindo uma experiência mais dinâmica e funcional para o usuário.
